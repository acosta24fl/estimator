Level

A homeowner whose DIY cabinets are almost right learns, alongside a meticulous installer, what right actually looks like.

10 shots · 37.0 s of footage · characters @Installer, @Homeowner

How to use this pack

  1. Character sheets: paste each prompt in Section 1 into Midjourney v7 / Flux / Ideogram. Keep the best sheet per character and name it after the tag (e.g. Installer.png).
  2. Clean plates: do the same for Section 2 (e.g. Kitchen_Plate.png). No people should appear. Regenerate if any do.
  3. Shots: in Seedance / Kling / Runway / Higgsfield, upload the reference images listed on each shot, paste its prompt, and render at 480p first.
  4. When a preview looks right, approve it (python -m cinepipe approve <project> SH0x0) and render that shot at 1080p with the same seed.
  5. Edit the clips in order, add music, and finish with the end card from the motion-studio film.

The storyboard frames are composition guides from the animated version, not the final look. Aim for real photography in the same layout.
